9) Python + Arduino Workflow
----------------------------
- Python sends commands via Serial
- Arduino performs calibration / sensor read
- Python stores results in offsets.txt
- Offsets sent back to Arduino on demand
- No auto-offset on boot (manual trigger with 'g')


10) Important Rules (Very Important)
------------------------------------
- .ino files must contain ONLY valid C/C++ code
- Notes / explanations MUST be in:
  - info.txt
  - README.md
  - comments (// or /* */)
- NEVER paste plain English into .ino without comments
- Arduino CLI is stricter than Arduino IDE

12) Installing Arduino Libraries (2 Ways)
-----------------------------------------

There are TWO ways to install Arduino libraries.
We are using WAY 1 (recommended).

-----------------------------------------
WAY 1 (Recommended – Uses Arduino IDE)
-----------------------------------------
This is what we are already doing.

Steps:
1. Open Arduino IDE
2. Go to:
   Sketch → Include Library → Manage Libraries
3. Search and install required libraries
   (example: SparkFun ISM330DHCX, CheapStepper, etc.)

Where libraries are stored:
S:\ujwal sahu\OneDrive\Documents\Arduino\libraries

Why this works:
- Arduino IDE and Arduino CLI share the SAME library folder
- No duplicate installs
- No version mismatch
- Arduino CLI automatically finds libraries

✔ This is the BEST and simplest method


-----------------------------------------
WAY 2 (CLI-only Method – Optional)
-----------------------------------------
Use this ONLY if you do NOT have Arduino IDE installed.

Example:
arduino-cli lib update-index
arduino-cli lib install "SparkFun 6DoF ISM330DHCX"
arduino-cli lib install "CheapStepper"

Libraries will still be installed into:
directories.user (from arduino-cli.yaml)

Downside:
- Harder to manage
- Library names must be exact
- Less visual control


-----------------------------------------
How to Verify Library Installation
-----------------------------------------
Run:
arduino-cli lib list

Or check folder:
S:\ujwal sahu\OneDrive\Documents\Arduino\libraries


-----------------------------------------
Important Rules for Libraries
-----------------------------------------
- Do NOT mix multiple library folders
- Do NOT copy libraries manually unless necessary
- Always include headers properly in .ino:
  #include <Wire.h>
  #include <SparkFun_ISM330DHCX.h>
- If compilation fails:
  → Check library name
  → Check library path
  → Check include order
